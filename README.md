# 🚀 Bikcraft

O **Bikcraft** é um projeto de site e-commerce e institucional focado na venda de bicicletas elétricas personalizadas, seguros e acessórios de alta performance. O projeto combina um design elegante com uma sólida arquitetura front-end, animações fluidas, foco em acessibilidade e otimização para motores de busca (SEO).

## 💎 Diferenciais Técnicos e Refatoração

- **Animações Fluidas por Componentes:** Integração e aplicação de plugins de animação em todas as páginas do ecossistema do site, garantindo dinamismo e interatividade ao navegar.
- **Integração Dinâmica de Mapas com CSS Filters:** Substituição de elementos estáticos por iFrames do Google Maps integrados com filtros CSS customizados (`grayscale`), proporcionando um visual _dark/gray_ moderno e interatividade total nas páginas de contato/lojas.
- **Otimização com Preload:** Carregamento rápido e prioritário de folhas de estilo unindo recursos críticos via `<link rel="preload">` e minificação de CSS, reduzindo o tempo de _First Contentful Paint_ (FCP).
- **Arquitetura CSS Modular & Grid System:** Organização limpa do código por módulos, utilizando técnicas avançadas de CSS Grid e Flexbox para layouts complexos e responsivos.
- **Design System com CSS Variables:** Padronização completa de cores, tipografia, espaçamentos e variáveis globais (`:root`).
- **HTML Semântico & SEO:** Estrutura rica em tags semânticas, acessibilidade (`aria-labels`), tratamento de formulários e preparação completa de metadados para buscadores.
